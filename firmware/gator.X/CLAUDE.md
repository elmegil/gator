# CLAUDE.md - firmware/gator.X

## Purpose
MPLAB X project containing all firmware for the Hook's Gator trigger sequencer. Targets PIC16F15345 running at 8 MHz (`OSCFRQ = 0b011` = 8 MHz, `_XTAL_FREQ = 8000000` — consistent). Single source file; build artifacts are checked in.

## Key Files
- **main.c**: Entire firmware — init, ISR, ADC reads, main loop
- **Makefile / nbproject/**: MPLAB X build system; open in MPLAB X IDE or build via `make`
- **dist/default/production/gator.X.production.hex**: Flash image ready to program
- **dist/default/debug/**: Debug build artifacts

## Architecture

### Initialization
- `Init_PIC()`: Configures oscillator, disables unused peripherals (PMD registers), sets port directions/pull-ups, configures ADC
- `Init_interrupts()`: Sets up Timer 0 as the sequencer clock tick (1 ms resolution via `TM0COUNT = 225`, prescaler 1:64, Fosc/4 source)

### ISR (`__interrupt() ISR`)
Fires every ~1 ms from Timer 0. Handles all timing-critical sequencer logic:
Two interrupt sources handled in one vector:
- **IOC (PIE0/PIR0 bit 6, IOCCF bit 2)**: fires on RC2 rising edge; calls `advance_step()` and immediately writes PORTC gate-on. Checked first to minimise latency (~2–15µs depending on whether timer ISR was already running).
- **Timer 0 (PIE0/PIR0 bit 5)**: fires every ~1ms; increments `clock0` and writes PORTC gate-off when `clock0 > duty`. Also handles internal-clock step advance (`clkpresent == 1`), stopped state (LED held on), and reset state (LED off, position reset).
- `advance_step()` is a static helper (shared by both paths): flips `evenodd`, resets `clock0`, advances `row`/`column`, handles wrap for both 2x8 and 1x16 modes
- Swing offsets the beat period via `offset` (±fraction of `period`); duty cycle proportionally adjusted per-phase (`adj_duty_pos`/`adj_duty_neg` precomputed in main loop)
- Reset input (`RA5`) returns sequencer to start position

### ADC (`Acquire`)
Reads a 10-bit ADC value from the specified channel. Channels:
- `rate`  = RB5 → tempo (mapped through `curve[]` lookup table)
- `width` = RB4 → gate duty cycle
- `steps` = RB6 → sequence length (1–8 or 1–16)
- `swing` = RB7 → swing amount (offsets odd beats; period offset and proportional duty adjustment both implemented)

### Speed Curve
`curve[1024]` — 6th-order polynomial lookup table mapping raw ADC (0–1023) to clock-tick period values (8–10199). Generated by Perl script embedded in comments. Provides logarithmic feel to the rate knob.

## Pin Map (PIC16F15345)
| Pin define | Port | Direction | Function |
|------------|------|-----------|----------|
| addrA/B/C  | RC3/4/5 | Out | 4051 address (step select) |
| inh1/inh2  | RC6/7 | Out | 4051 chip enable (active low via transistor inversion) |
| ckout      | RC0 | Out | Gate/clock output |
| runstop    | RA2 | In | Run=1 / Stop=0 |
| updown     | RA4 | In | Up=0 / Down=1 |
| reset      | RA5 | In | Active low (hardware location unverified) |
| mode       | RC1 | In | 2x8=0 / 1x16=1 |
| intclk     | RC2 | In | External clock input (rising-edge detection, WPUC pull-up enabled) |
| clkpresent | RA3 | In | Stereo-jack cable detect; 1=no cable (use internal clock), 0=cable present (use external clock). Shares MCLR/Vpp pin — see Known Issues |

## Known Issues / TODOs
- **clkpresent / RA3**: RA3 doubles as MCLR (`MCLRE = ON`, required for ICSP). Cable-detect circuit must not pull RA3 below the MCLR reset threshold (~0.2×Vdd). A single diode (even Schottky) is insufficient — the forward drop stays below 1V at 5V. Hardware protection scheme TBD. `extclk_timeout` globals remain in code but are unused — dead code to be cleaned up.
- **Duty cycle with external clock**: `duty` is computed from the internal `period` (rate pot), not the actual external clock period. At large mismatches the gate duration won't be proportional to the external beat. Unresolved.
- **INTCON block in main()**: Disables interrupts briefly for duty/offset update (~20–30 cycles). Can delay an IOC edge by up to ~15µs; acceptable for Eurorack use.
- **reset pin**: Hardware location still unverified (RA5).
- Old test code left at bottom of main.c in a block comment.
